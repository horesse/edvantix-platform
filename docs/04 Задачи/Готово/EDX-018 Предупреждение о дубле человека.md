# EDX-018 · Мягкое предупреждение о возможном дубле при создании человека

> [!success] Готово · 2026-09-03 · branch `claude/edx-018-duplicate-person-warning-b1aca0`
> `GET /api/v1/people/duplicate-candidates?lastName=&firstName=&phone=&email=` —
> запрос-проверка по модулю People: точное совпадение фамилии + имени (SQL `ILIKE`
> без шаблонов) И совпадение телефона (только цифры, `+7 900 111-22-33` ≡
> `+79001112233`) **или** e-mail. Возвращает `DuplicatePersonCandidateDto`
> (`PersonType` = Student/Teacher/Guardian, `DisplayName`, контакты, флаги
> `PhoneMatches`/`EmailMatches`). Совпадения только по имени отбрасываются —
> семья с одним телефоном на нескольких детей предупреждение не поднимает.
> Без прав (все три «View» — `IsBasic`), без нового уникального индекса.
>
> FE: `DuplicatePersonNotice` (`src/components/duplicate-person-notice.tsx`) —
> неблокирующая плашка в диалогах создания ученика / представителя /
> преподавателя, дебаунс 400 мс, ссылки на карточки открываются в новой вкладке.
> Пока есть кандидаты, кнопка диалога меняется на «Всё равно создать»; создание
> не запрещается.
