# EDX-005 · Вкладка «История» (аудит) на карточке ученика

## Контекст

`clients/dashboard/src/pages/people/student-detail.tsx` содержит вкладки
`guardians / groups / attendance / billing`, но не `history`. Бэкенд готов с PR #15:

- `GET /api/v1/audits/by-entity/{entityName}/{entityId}` — история конкретной сущности.
- `GET /api/v1/audits/entity-labels` — читаемые метки типов/полей (уже используется на `/audits`).

Карта экранов помечает `/students/:id` как 🔧: «история — после Auditing».
В план frontend-этапов вкладка не попала — подтвердить у продукта, нужна ли в MVP;
техническая часть тривиальна.

## Что сделать

- [x] Вкладка «История»: список событий по `entityName = "Student"` (подтверждено —
      `EntityDiffBuilder` пишет `entityType.ClrType.Name`, т.е. `"Student"`),
      `entityId = student.id`, через `GET /api/v1/audits/by-entity/Student/{id}`,
      постранично (`EntityPager`, 20/стр). Строки раскрываются и дозагружают
      `GET /api/v1/audits/{id}` ради изменённых полей; имена полей/операция —
      через `entity-labels` + `ENTITY_OPERATION_LABELS`.
- [x] Гейт `Permissions.AuditTrails.View` (то же право, что у `/system/audits`).
- [x] Playwright (route-mocked): `tests/people/student-history.spec.ts` — рендер строк +
      раскрытие до переведённых полей, и скрытие вкладки без права.
- [x] Обновить [[Карта экранов]] (`/students/:id` — вкладка «История» ✅; остаётся 🔧 по
      [[EDX-006 Убрать устаревшую заглушку на карточке ученика]]).
