# EDX-014 · Редактор шаблона нумерации счетов на `/school/settings`

> [!success] Готово · 2026-09-03 · branch `claude/edx-014-invoice-numbering-editor-50aa65`
> Секция «Нумерация счетов» на `/school/settings` больше не заглушка: поле
> `invoiceNumberTemplate` с клиентской валидацией (зеркалит
> `InvoiceNumberFormat.IsValid`) и предпросмотром следующего номера. Сохраняется
> общей кнопкой формы в тот же `PUT /api/v1/tenants/settings`; read-only без
> `SchoolSettings.Manage`.

## Контекст

`clients/dashboard/src/pages/settings/school.tsx` — секция «Нумерация счетов»
была read-only-заглушкой. Разблокировано [[EDX-013 Настраиваемый шаблон номера счёта]]:
`TenantSettings.InvoiceNumberTemplate` отдаётся/принимается через
`GET`/`PUT /api/v1/tenants/settings` (`invoiceNumberTemplate`; `null` в `PUT` = «не менять»).

## Что сделано

- [x] Поле «Шаблон номера» + подсказка с плейсхолдерами (`{YYYY}` / `{YY}` / `{MM}` /
      `{N…}`) и предпросмотром следующего номера (рендер зеркалит
      `InvoiceNumberFormat.Render`, дата — UTC, счётчик в превью = 1 с оговоркой,
      что реальный продолжается с текущей позиции школы).
- [x] Клиентская валидация (только известные токены, без лишних `{}`/`>64` символов,
      обязателен хотя бы один `{N…}`) — при ошибке `role="alert"` и Save заблокирован.
- [x] Селект политики обнуления не добавлялся — правило выводится из шаблона
      (год в шаблоне ⇒ сброс по годам) и показано текстом в подсказке.
- [x] Уходит в общий `PUT /api/v1/tenants/settings` (поле `invoiceNumberTemplate`,
      всегда полная строка); поле `disabled` без `SchoolSettings.Manage`.
- [x] Playwright: 4 новых теста (`tests/settings/school.spec.ts`) + правка двух
      существующих на новое поле в payload; [[Карта экранов]] — оговорка про заглушку снята.
