# EDX-015 · Автоблокировка доступа к материалам при задолженности

> [!success] Готово · 2026-09-03 · PR #33

## Контекст

Из [[Открытые вопросы]] → Payments: «Просят часто. Продуктовое решение, не техническое».
Предложение оттуда: флаг тенанта, по умолчанию выключен; блокировать **материалы**, но
не расписание (иначе ученик не придёт на уже оплаченное преподавателю занятие).

## Принятое правило

- Флаг тенанта `TenantSettings.RestrictMaterialsOnDebt`, **по умолчанию выключен**;
  грейс-период `TenantSettings.DebtGraceDays` (по умолчанию 7, диапазон 0–90).
- **Блокируем:** `GET /lessons/{id}/materials` (403) и выдачу ссылок на файлы материалов
  (`LessonMaterialAccessPolicy`). Расписание/посещаемость/счета/чат — не трогаем.
- **Порог:** любой остаток по счёту в статусе `Issued`/`PartiallyPaid` с `DueDate`
  старше грейса. Отдельного порога по сумме нет.
- **Не блокируем:** сотрудников (`PeopleScope.TeacherId` задан), менеджеров/админов
  (пустой `PeopleScope`). Представителя — по конкретному подопечному-должнику.
- Записано в `docs/02 Модули/Payments.md` → «Автоблокировка доступа к материалам»,
  снято из [[Открытые вопросы]].
