# EDX-019 · Индикатор прогресса по программе курса

## Контекст

Из [[Открытые вопросы]] → Curriculum: «Прошли 12 из 40 уроков». Принятое предложение —
считать **на лету** из проведённых `Session` с непустым `LessonId`, проекцию не заводить,
пока не станет медленно.

## Что сделать

- [x] Запрос: для группы вернуть `passedLessons / totalLessons` курса —
      `total` из `Modules.Curriculum` (уроки курса), `passed` из `Modules.Scheduling`
      (уникальные `LessonId` у занятий в терминальном «проведено» статусе `Held`,
      пересечённые с текущим набором уроков курса). Контракт наружу через `.Contracts`.
- [x] FE: индикатор на `/study-groups/:id` (секция «Прогресс по программе» — «Пройдено N
      из M уроков» + полоса) и на `/students/:id` вкладке «Группы» (строка прогресса
      у действующих зачислений).
- [x] Без хранимой проекции; порог перехода на проекцию отмечен в
      `docs/02 Модули/Curriculum.md` → «Чего в модели нет намеренно».

## Реализация

Запрос живёт в Scheduling, не Curriculum (как `GetTeacherWorkloadQuery`): `total` — из
`ICourseQueryService.GetLessonsInOrderAsync`, `passed` — собственные `Session` модуля.

- `Modules.Scheduling.Contracts`: `CourseProgressDto`,
  `v1/StudyGroups/GetGroupCourseProgressQuery` (не пагинируемый → без валидатора).
- `Modules.Scheduling/Features/v1/StudyGroups/GetGroupCourseProgress/` — handler + endpoint
  `GET /api/v1/study-groups/{id}/course-progress`, гейт `SchedulingPermissions.Sessions.View`,
  404 если группы нет. Зарегистрирован в `SchedulingModule.MapEndpoints`.
- Тесты: `Scheduling.Tests/Features/GetGroupCourseProgressQueryHandlerTests` (дедуп,
  фильтр по статусу/группе/принадлежности уроку курса), `Integration.Tests/Tests/Scheduling/
  GetGroupCourseProgressTests` (провести 3 занятия по курсу на 10 уроков → «3 из 10» + 404).
- FE: `api/scheduling.ts` — `CourseProgressDto` + `getGroupCourseProgress`;
  `study-group-detail.tsx` — `CourseProgressSection`; `student-detail.tsx` —
  `GroupCourseProgressLine` в `GroupsTab` (гейт `Scheduling.Sessions.View`).
- Playwright: `tests/study-groups/course-progress.spec.ts` (рендер/пустой курс/гейт),
  `tests/study-groups/student-groups.spec.ts` дополнен.
- Doc: [[Curriculum]] (порог проекции), [[Scheduling]] (запрос + примечание + HTTP API),
  [[Карта экранов]].
