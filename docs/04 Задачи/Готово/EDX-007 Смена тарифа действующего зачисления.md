## Контекст

`GroupEnrollment.TariffId` и `DiscountPercent` задаются только при зачислении
(`EnrollStudentsCommand`) и переносятся при переводе (`TransferEnrollment`). Отдельного
write-эндпоинта, меняющего тариф действующего зачисления без переоформления, нет —
жизненный цикл в `Modules.StudyGroups` это Enroll / Transfer / Pause / Resume / Unenroll.

Из-за этого во frontend (`EnrollDialog`, см. [[EDX-003 Тариф в диалоге зачисления]])
тариф можно указать только в момент зачисления.
