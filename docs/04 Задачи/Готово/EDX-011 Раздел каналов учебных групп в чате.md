# EDX-011 · Раздел/фильтр каналов учебных групп на `/chat`

> [!success] Готово · 2026-09-03 · PR #38

## Контекст

С карточки группы есть ссылка «Чат группы» по `chatChannelId` (этап 7), но в самом
`/chat` каналы групп не выделены — их не отличить от обычных. Карта экранов: `/chat` 🔧.

## Что сделано

- [x] `channel-rail` — отдельная секция «Study Groups» перед «Channels». Каналы
      учебных групп (`ChannelDto.sourceStudyGroupId` задан, EDX-010) больше не
      мешаются среди ad-hoc каналов. Секция read-only — без кнопки «+».
- [x] В строке канала группы — ссылка-стрелка (`ArrowUpRight`) на
      `/study-groups/:studyGroupId` по `sourceStudyGroupId`. Реализована как
      `<Link>`-сосед кнопки выбора канала (вложенный `<a>` в `<button>` невалиден).
- [x] Playwright: `tests/chat/chat.spec.ts` → describe «chat — study group
      channels» — секция рендерится, канал группы внутри неё, ad-hoc канал вне,
      ровно одна строка с deep-link на нужную группу.
- [x] Обновлены [[Карта экранов]] (`/chat` → ✅) и [[Chat]].

## Реализация

- `clients/dashboard/src/api/chat.ts` — `ChannelDto.sourceStudyGroupId?: string | null`.
- `clients/dashboard/src/pages/chat/channel-rail.tsx` — сплит `studyGroupChannels`
  в `useMemo`; `Section` c опциональным действием; `ChannelRow` принимает `groupId`,
  меняет иконку на `GraduationCap` и рисует trailing `<Link>`.
