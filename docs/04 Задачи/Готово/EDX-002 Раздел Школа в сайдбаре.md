# EDX-002 · Раздел «Школа» в сайдбаре

> [!success] Готово · 2026-09-02 · PR #31

## Контекст

Настройки школы жили вкладкой внутри личных настроек `/settings/*`, что смешивало
персональное и общешкольное.

## Что сделано

- [x] Новый раздел сайдбара **«Школа»** (`nav-data.ts`, `id: "school"`): «Настройки
      школы» (`SchoolSettings.Manage`), «Аудитории» (`Scheduling.Rooms.View`),
      «Нерабочие дни» (`Scheduling.ScheduleTemplates.View`) — каждый гейтится своим правом.
- [x] Экраны переехали под `/school/*`; старые `/settings/{school,rooms,non-working-days}`
      оставлены редиректами.
- [x] Личный `/settings` — только личные вкладки с RU-подписями.
- [x] Командная палетка, `SchoolSettings` получил свой `PageHero`; 238 Playwright зелёных.
