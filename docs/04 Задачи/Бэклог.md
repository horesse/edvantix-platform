# Бэклог

← [[Edvantix]]

Единственное место, где живёт «что нужно сделать». Раздел [[Карта модулей|02 Модули]] —
справочник (что модуль представляет собой и какие у него контракты), без планов.

## Как ведём задачи

**Одна задача — один файл.** Файл называется `EDX-NNN Короткое название.md`, лежит в
этой папке. `NNN` — сквозной номер, **никогда не переиспользуется**.

### Frontmatter (обязателен)

```yaml
---
key: EDX-007
aliases: [EDX-007]        # чтобы [[EDX-007]] резолвился без полного имени
tags: [задача, backend]   # + область: frontend / backend / ops / docs / product
status: open              # open | blocked | in-progress | done
area: backend             # dashboard | admin | backend | ops | docs
priority: p2              # p1 (сейчас) | p2 (скоро) | p3 (когда-нибудь)
blocked-by: []            # ["[[EDX-013 ...]]"]  — что должно быть сделано раньше
blocks: []                # ["[[EDX-014 ...]]"]  — что ждёт эту задачу
related: []               # смежные задачи и вопросы
created: 2026-09-03
closed:                   # дата закрытия + PR, только когда status: done
---
```

### Тело

- `## Контекст` — почему задача есть, где именно в коде (файлы/строки, эндпоинты).
- `## Что сделать` — чек-лист.
- `## Зависимости` — дублирует `blocked-by` / `blocks` / `related` человекочитаемо.
- `## Проверка` — как убедиться, что готово (команды, сценарии).

### Статусы и пометка выполненных

| Статус | Что значит | Где лежит файл |
|---|---|---|
| `open` | можно брать | `docs/04 Задачи/` |
| `blocked` | ждёт другую задачу (см. `blocked-by`) | `docs/04 Задачи/` |
| `in-progress` | кто-то делает | `docs/04 Задачи/` |
| `done` | сделано и слито | **перемещается в** `docs/04 Задачи/Готово/` |

Закрывая задачу: `status: done`, заполнить `closed:`, дописать в начало тела
`> [!success] Готово · <дата> · PR #NN`, **переместить файл** в `Готово/`.
`aliases: [EDX-NNN]` гарантирует, что ссылки `[[EDX-NNN]]` не сломаются после переезда.
В индексе ниже строка переезжает из «Открытые» в «Готово».

### Связи

Блокираторы и зависимости проставляются **с обеих сторон**: если `EDX-014` имеет
`blocked-by: [[EDX-013]]`, то у `EDX-013` должно быть `blocks: [[EDX-014]]`.
