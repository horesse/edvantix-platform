## Определение готовности

Этап не считается законченным, пока не выполнено всё:

- [ ] `dotnet build src/Edvantix.slnx` без предупреждений (`TreatWarningsAsErrors`)

      у обработчиков, наличие валидаторов
- [ ] интеграционный тест изоляции тенантов на каждую новую сущность
- [ ] Playwright на основные сценарии этапа
- [ ] написан `.agents/rules/modules/{name}.md`
- [ ] справочник в `docs/02 Модули/` приведён в соответствие с реализацией
- [ ] публичная документация и changelog обновлены — правило 10 из `AGENTS.md`
