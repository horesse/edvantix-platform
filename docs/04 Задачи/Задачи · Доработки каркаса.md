# Задачи · Доработки каркаса

← [[Бэклог]]

Работы по существующим модулям. Что каждый модуль представляет собой и какие у него
контракты — в его справочнике в разделе «Модули».

> [!warning] Правило 4 из `AGENTS.md`
> `src/BuildingBlocks` не трогаем без явного согласования — общий для всех модулей,
> широкий радиус поражения.

> [!success] Каркас закрыт
> Реализовано и слито в `main` (PR #1, #10, #11, #13, #15, #17, #20):
>
> - **Multitenancy** — `TenantSettings` (часовой пояс IANA, валюта ISO 4217,
>   `ITenantSettingsService` на `HybridCache`, миграция с бэкофиллом, права
>   `SchoolSettings.*`); провижининг новых школ сидит базовые направления и тариф по
>   умолчанию.
> - **Identity** — сид школьных ролей (`SchoolAdmin`/`Manager`/`Teacher`/`Student`/
>   `Guardian`) + `RolePermissionSyncer`; приглашение по e-mail (`InviteUserCommand`,
>   письмо со ссылкой `/accept-invite`, `EmailConfirmed` при приёме, привязка к
>   `Guardian`/`Student`).
> - **Chat** — приватный канал на `StudyGroupCreated`, синхронизация участников на
>   enroll/unenroll (учёт учеников без учётки через опекуна-плательщика), блокировка
>   канала на `StudyGroupFinished`, DM-политика (`IChatDmPolicy`).
> - **Notifications** — шаблоны с подстановкой (`Templating/`), подписчики школьных
>   событий Scheduling/Payments/StudyGroups, настройки подписок пользователя, тихие
>   часы по времени школы, дедуп/дайджест, абстракция `INotificationChannel`.
> - **Webhooks** — каталог типов событий (`WebhookEventCatalog`, 24 типа,
>   `GET /api/v1/webhooks/event-types`), публичный конверт `WebhookEnvelope` (v1),
>   тенант-скоуп прав подписок школы.
> - **Files** — лимиты объёма по плану через `BuildingBlocks/Quota` (активированы,
>   школьные лимиты `free`/`pro`/`pro-annual`), белый список типов для материалов
>   уроков (видео-контейнеры исключены), видео — только ссылкой на разрешённый хостинг.
> - **Billing** — предметные метрики `UsageSnapshot` (активные ученики/преподаватели/
>   группы/занятия за месяц/объём файлов), мягкая блокировка создания при превышении
>   (`QuotaExceededException` → HTTP 402), названия планов под школу + `Description`.
> - **Tickets** — категории (`TicketCategory` + `Audience` по умолчанию), привязка к
>   контексту (`RelatedStudentId`/`RelatedStudyGroupId`/`RelatedInvoiceId`), вложения
>   через Files (`TicketFileAccessPolicy`).
> - **Auditing** — ручные записи через `IAuditClient` для не-CRUD действий, читаемые
>   метки (`AuditLabelCatalog`, `GET /api/v1/audits/entity-labels`), история конкретной
>   сущности (`GET /api/v1/audits/by-entity/...`), `AuditRetentionOptions` в конфиге.
>
> Обоснования проектных решений — в справочниках `docs/02 Модули/` и
> `.agents/rules/modules/`.
