# EDX-013 · Настраиваемый шаблон номера счёта ученика

## Контекст

`StudentInvoice.GenerateNumber` нумерует счета рабочей схемой без настраиваемого
шаблона (см. `docs/02 Модули/Payments.md`; в PR #12 чинился баг коллизий на пакетном
выпуске — брались старшие биты Guid v7 вместо младших). Из [[Открытые вопросы]] →
Payments: нужна настройка тенанта с шаблоном (`{YYYY}-{NNNN}`), по умолчанию сквозная;
требования отличаются по юрисдикциям.

`clients/dashboard/src/pages/settings/school.tsx:250` уже показывает секцию
«Нумерация счетов» с текстом «задаётся сервером автоматически и не настраивается из
интерфейса» — ждёт эту задачу.

## Что сделать

- [ ] Продукт: зафиксировать набор плейсхолдеров (`{YYYY}`, `{YY}`, `{NNNN}`,
      `{MM}`?), политику обнуления (сквозная / по годам), поведение при смене шаблона
      посреди года. Записать решение в `docs/02 Модули/Payments.md` и убрать пункт из
      [[Открытые вопросы]].
- [ ] Настройка на уровне тенанта (`TenantSettings` в `Modules.Multitenancy`, рядом с
      TZ/валютой) — `InvoiceNumberTemplate`, дефолт `{YYYY}-{NNNN}`.
- [ ] `GenerateNumber` читает шаблон; счётчик per-tenant (+ per-year при обнулении),
      конкурентно-безопасный на пакетном выпуске.
- [ ] Миграция + бэкофилл дефолта, интеграционный тест на пакетную генерацию без коллизий.
