# EDX-016 · Справочник полей `data` каждого типа события вебхука

## Контекст

Каталог типов есть в коде: `WebhookEventCatalog` (24 типа,
`GET /api/v1/webhooks/event-types`), публичный конверт `WebhookEnvelope` (v1). Чего не
хватает интеграторам — описания полей `data` для каждого типа события.

Раньше это числилось как «залить в публичный docs-репозиторий `github.com/fullstackhero/docs`».
Внешнего репозитория больше нет (правило 10 переписано) — документируем **здесь**, в
`docs/02 Модули/Webhooks.md`.

## Что сделать

- [ ] В `docs/02 Модули/Webhooks.md` — таблица по каждому из 24 типов: ключ события,
      когда шлётся, JSON-схема/поля `data` с типами и примером.
- [ ] Источник истины — записи `WebhookEventCatalog` и соответствующие integration-события
      (`*IntegrationEvent` в модулях); при расхождении править код/каталог.
- [ ] Ссылку на этот раздел — из `README`/OpenAPI-описания эндпоинта `event-types`.
