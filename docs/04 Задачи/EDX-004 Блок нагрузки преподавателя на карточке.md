# EDX-004 · Блок нагрузки/групп/расписания на карточке преподавателя

## Контекст

`clients/dashboard/src/pages/people/teacher-detail.tsx:252-257` — секция «Нагрузка»
это заглушка: «Блок нагрузки появится после подключения модулей StudyGroups и
Scheduling». Оба модуля давно в `main`, а бэкенд-эндпоинт уже есть:

- `GET /api/v1/teachers/{teacherId}/workload` → `TeacherWorkloadDto`
  (`from`, `to`, число активных групп, число занятий, суммарные часы) —
  `Modules.Scheduling`, PR #8. Окно по умолчанию — 7 дней вперёд
  (`SchedulingDefaults.DefaultWorkloadWindowDays`).

Карта экранов помечает `/teachers/:id` как 🔧: «нагрузка, группы, расписание — после модулей».

## Что сделать

- [ ] API-модуль: `getTeacherWorkload(teacherId, { from, to })` в `src/api/`.
- [ ] Секция «Нагрузка»: активные группы / занятия за период / часы, выбор окна
      (7 / 14 / 30 дней), гейт на `Permissions.Scheduling.*` (сверить точное право эндпоинта).
- [ ] Секция «Группы преподавателя»: список групп, где он ведущий
      (`GET /api/v1/study-groups?teacherId=`), ссылки на `/study-groups/:id`.
- [ ] Ссылка «Расписание преподавателя» → `/schedule?teacherId=<id>` (фильтр уже есть).
- [ ] Playwright: секция рендерится, показывает данные, gated без права.
- [ ] Обновить [[Карта экранов]] (`/teachers/:id` → ✅).
