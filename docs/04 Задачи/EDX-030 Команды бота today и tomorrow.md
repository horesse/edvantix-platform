# EDX-030 · Команды бота `/today` и `/tomorrow`

## Контекст

После привязки бот умеет только `/start`, `/stop`, `/help`. Самый частый вопрос родителя
«во сколько сегодня занятие?» можно закрыть без входа в кабинет. Данные есть:
`IMyScheduleReader` ([[EDX-012 Экспорт расписания в iCal]]) отдаёт расписание пользователя;
для человека без учётки — расписание по ученику/подопечным (`GetMyScheduleQuery` идёт от
`UserId`, здесь нужен вариант от `RecipientKey`).

Задача p3: делать после того, как канал доставки поработает на первых школах и станет
ясно, спрашивают ли это родители.

## Что сделать

- [ ] `Scheduling.Contracts`: `IScheduleForRecipientReader.GetAsync(recipientKey, dateLocal)` —
      для учётки как `IMyScheduleReader`; для `email:` — через `IPeopleLookupService`
      найти ученика/представителя по e-mail (аддитивный метод `FindByEmailAsync`) и
      собрать занятия подопечных.
- [ ] Бот (`ITelegramUpdateHandler`): `/today`, `/tomorrow` — по всем активным привязкам
      чата (несколько школ → сгруппировать по школе). Ответ: «<b>Сегодня, ср 10 сент</b>
      \n18:00–19:30 · EN-A1-03 · Иванова А. · онлайн» + кнопка «Открыть расписание».
      Пусто → «Сегодня занятий нет». Время — в поясе школы.
- [ ] `/help` — дополнить двумя командами; `setMyCommands` при старте (меню команд в клиенте).
- [ ] Лимит: не чаще 20 запросов в минуту с чата.

## Зависимости

- Блокируется: [[EDX-023 Привязка получателя к Telegram]]

## Проверка

- `Notifications.Tests`: форматирование ответа, пустой день, две школы.
- Руками: привязанный родитель двух детей в одной школе получает объединённый список
  без дублей.
