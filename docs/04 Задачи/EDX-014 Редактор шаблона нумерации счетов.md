# EDX-014 · Редактор шаблона нумерации счетов на `/school/settings`

## Контекст

`clients/dashboard/src/pages/settings/school.tsx:250` — секция «Нумерация счетов»
сейчас read-only-заглушка: «Пока задаётся сервером автоматически и не настраивается из
интерфейса». Разблокировано: [[EDX-013 Настраиваемый шаблон номера счёта]] завезло
`TenantSettings.InvoiceNumberTemplate` (см. [[Payments]] → «Нумерация счетов» — набор
плейсхолдеров и правило обнуления). Бэкенд отдаёт/принимает поле через
`GET`/`PUT /api/v1/tenants/settings` (`invoiceNumberTemplate`; `null` в `PUT` = «не менять»).

## Что сделать

- [ ] Поле «Шаблон номера» + подсказка с доступными плейсхолдерами и предпросмотром
      следующего номера.
- [ ] Селект политики обнуления не нужен — правило выводится из шаблона (год в шаблоне ⇒
      сброс по годам); достаточно показать это в подсказке.
- [ ] Идёт в тот же `PUT /api/v1/tenants/settings` (поле `invoiceNumberTemplate`); read-only
      без `SchoolSettings.Manage`.
- [ ] Playwright, обновить [[Карта экранов]] (снять оговорку про заглушку).

## Зависимости

- Блокируется: — (разблокировано [[EDX-013 Настраиваемый шаблон номера счёта]])

## Проверка

- Aspire: сменить шаблон → следующий выпущенный счёт получает номер по нему.
