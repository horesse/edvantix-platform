# EDX-012 · Экспорт расписания в iCal

## Контекст

Из [[Открытые вопросы]] → Scheduling: «Попросят почти сразу. Реализуемо тонким
эндпоинтом поверх `GetMyScheduleQuery`. Вопрос только в приоритете». Развязано в задачу.

## Что сделать

- [ ] `GET /api/v1/my/schedule.ics` — VCALENDAR из ближайших занятий пользователя
      (та же выборка, что `GetMyScheduleQuery`), TZ школы, `UID` = id занятия,
      обновление события при переносе.
- [ ] Аутентификация: по токену в query (для подписки в календарном клиенте) —
      одноразовый персональный ical-токен, отзываемый; согласовать с
      [[EDX-008 API-ключи в Identity]], возможно переиспользовать механизм.
- [ ] FE: на `/my/schedule` — кнопка «Добавить в календарь» (копирует ссылку с токеном).
- [ ] `docs/02 Модули/Scheduling.md`.
