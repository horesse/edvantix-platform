# EDX-005 · Вкладка «История» (аудит) на карточке ученика

## Контекст

`clients/dashboard/src/pages/people/student-detail.tsx` содержит вкладки
`guardians / groups / attendance / billing`, но не `history`. Бэкенд готов с PR #15:

- `GET /api/v1/audits/by-entity/{entityName}/{entityId}` — история конкретной сущности.
- `GET /api/v1/audits/entity-labels` — читаемые метки типов/полей (уже используется на `/audits`).

Карта экранов помечает `/students/:id` как 🔧: «история — после Auditing».
В план frontend-этапов вкладка не попала — подтвердить у продукта, нужна ли в MVP;
техническая часть тривиальна.

## Что сделать

- [ ] Вкладка «История»: таблица событий по `entityName = "Student"` (сверить фактическое
      имя сущности в аудите), `entityId = student.id`, пагинация, метки через `entity-labels`.
- [ ] Гейт на право чтения аудита (`Permissions.Auditing.*` — сверить).
- [ ] Playwright (route-mocked) на рендер и на скрытие без права.
- [ ] Обновить [[Карта экранов]] (`/students/:id` → ✅).
