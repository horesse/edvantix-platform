# EDX-015 · Автоблокировка доступа к материалам при задолженности

## Контекст

Из [[Открытые вопросы]] → Payments: «Просят часто. Продуктовое решение, не техническое».
Предложение оттуда: флаг тенанта, по умолчанию выключен; блокировать **материалы**, но
не расписание (иначе ученик не придёт на уже оплаченное преподавателю занятие).

## Что сделать

- [ ] Продукт: подтвердить правило (что блокируем, с какого порога долга / просрочки,
      грейс-период, кого не блокируем). Записать в `docs/02 Модули/Payments.md`, снять из
      [[Открытые вопросы]].
- [ ] Backend: флаг тенанта (`TenantSettings`), сервис-проверка «есть ли блокирующая
      задолженность у ученика» (переиспользовать выборку должников `/reports/debtors`),
      применить в политике доступа к материалам уроков (`Modules.Curriculum` / Files).
- [ ] FE: в кабинете ученика/представителя — понятная плашка «доступ ограничен из-за
      задолженности» со ссылкой на `/my/invoices`.
- [ ] Тест изоляции тенантов + интеграционный тест сценария блок/разблок.

## Зависимости

- Блокируется: — (нужно продуктовое решение)
- Связано: [[Открытые вопросы]]

## Проверка

- Интеграционный тест: просроченный счёт → материалы 403, расписание доступно; оплата → доступ вернулся.
