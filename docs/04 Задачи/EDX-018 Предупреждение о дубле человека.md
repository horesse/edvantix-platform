# EDX-018 · Мягкое предупреждение о возможном дубле при создании человека

## Контекст

Из [[Открытые вопросы]] → People: два «Иванов Иван» с одним телефоном. Жёсткий
уникальный индекс по телефону сломается на семьях с одним контактом на всех детей.
Принятое предложение — **мягкое предупреждение**.

## Что сделать

- [ ] Запрос-проверка: по ФИО + телефон/e-mail вернуть кандидатов-дублей
      (Student / Guardian / Teacher в рамках тенанта).
- [ ] FE: в диалогах создания ученика/представителя/преподавателя — неблокирующая
      плашка «Возможно, это дубль: …» со ссылками на карточки; создание не запрещаем.
- [ ] Без нового уникального индекса в БД.
