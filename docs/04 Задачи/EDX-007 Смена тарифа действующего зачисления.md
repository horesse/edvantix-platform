# EDX-007 · Смена тарифа/скидки у действующего зачисления

## Контекст

`GroupEnrollment.TariffId` и `DiscountPercent` задаются только при зачислении
(`EnrollStudentsCommand`) и переносятся при переводе (`TransferEnrollment`). Отдельного
write-эндпоинта, меняющего тариф действующего зачисления без переоформления, нет —
жизненный цикл в `Modules.StudyGroups` это Enroll / Transfer / Pause / Resume / Unenroll.

Из-за этого во frontend (`EnrollDialog`, см. [[EDX-003 Тариф в диалоге зачисления]])
тариф можно указать только в момент зачисления.

## Что сделать

- [ ] Команда + эндпоинт: `PATCH /api/v1/enrollments/{id}` (или узкий
      `PUT /api/v1/enrollments/{id}/tariff`) — меняет `TariffId` и/или `DiscountPercent`.
- [ ] Валидатор (`{Name}Validator`).
- [ ] Право: `Permissions.StudyGroups.Enrollments.Create` или новое `.Update`.
- [ ] Решить поведение для уже выпущенных счетов (не трогаем прошлые, применяем со
      следующего начисления) — зафиксировать в `docs/02 Модули/StudyGroups.md`.
- [ ] Тест изоляции тенантов + `Architecture.Tests`.
- [ ] FE: в ростере «Состав группы» на `/study-groups/:id` — действие «Сменить тариф».
