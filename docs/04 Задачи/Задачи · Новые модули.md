## Открытые пункты

- [ ] Публичный docs-репозиторий (`github.com/fullstackhero/docs`) и changelog —
      правило 10 `AGENTS.md`. Не сделано ни для одного из пяти модулей: ни у одной сессии
      реализации не было доступа к репозиторию. Делать одной отдельной сессией по всем
      модулям разом (см. [[Бэклог]]).
- [ ] **StudyGroups — смена тарифа/скидки у существующего зачисления.** Сейчас
      `GroupEnrollment.TariffId` и `DiscountPercent` задаются только при зачислении
      (`EnrollStudentsCommand`) и переносятся при переводе (`TransferEnrollment`).
      Отдельного write-эндпоинта, меняющего тариф действующего зачисления без
      переоформления, нет — во frontend (`EnrollDialog`, [[Задачи · Frontend]]) тариф
      можно указать только при зачислении. Нужно: команда + эндпоинт (напр.
      `PUT /api/v1/enrollments/{id}/tariff` или общий
      `PATCH /api/v1/enrollments/{id}`), валидатор, право
      `Permissions.StudyGroups.Enrollments.Create` (или новое `.Update`), затем
      прокинуть в UI ростера группы.
