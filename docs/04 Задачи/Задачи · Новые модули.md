# Задачи · Новые модули

← [[Бэклог]] · справочники: [[People]] [[Curriculum]] [[StudyGroups]] [[Scheduling]] [[Payments]]

Пять модулей с нуля. Домен и контракты каждого описаны в его справочнике —
здесь только работы.

## Общее для каждого модуля

Скелет по `.agents/skills/add-module/SKILL.md`, регистрация в четырёх местах —
[[Регистрация модуля]].

- [ ] Проекты `Modules.{Name}` и `Modules.{Name}.Contracts`
- [ ] `{Name}Module.cs` + `[assembly: FshModule(typeof({Name}Module), order)]`
- [ ] `{Name}Permissions.cs` + `PermissionConstants.Register` в `ConfigureServices`
- [ ] `{Name}DbContext` — `base.OnModelCreating` **последним**, схема модуля
- [ ] `{Name}DbInitializer` — сид справочников
- [ ] Папка миграций `src/Host/Edvantix.Migrations.PostgreSQL/{Name}/`
- [ ] Регистрация: `Api/Program.cs` (2 маркера + `moduleAssemblies`),
      `DbMigrator/Program.cs` (та же пара), `Edvantix.slnx`
- [ ] Проект тестов `src/Tests/{Name}.Tests/` + в `.slnx`
- [ ] `.agents/rules/modules/{name}.md`
- [ ] Интеграционный тест изоляции тенантов на каждую сущность
