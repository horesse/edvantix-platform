# EDX-019 · Индикатор прогресса по программе курса

## Контекст

Из [[Открытые вопросы]] → Curriculum: «Прошли 12 из 40 уроков». Принятое предложение —
считать **на лету** из проведённых `Session` с непустым `LessonId`, проекцию не заводить,
пока не станет медленно.

## Что сделать

- [ ] Запрос: для группы (или ученика) вернуть `passedLessons / totalLessons` курса —
      `total` из `Modules.Curriculum` (уроки курса), `passed` из `Modules.Scheduling`
      (уникальные `LessonId` у занятий в терминальном «проведено» статусе). Контракт
      наружу через `.Contracts`.
- [ ] FE: индикатор на `/study-groups/:id` и, опционально, на `/students/:id` (вкладка «Группы»).
- [ ] Без хранимой проекции; отметить в `docs/02 Модули/Curriculum.md` порог, за которым
      стоит перейти на проекцию.
