# EDX-029 · Напоминание за час до занятия

## Контекст

`SessionReminderJob` ([[Scheduling]], `Jobs/SessionReminderJob.cs`, cron `0 * * * *`)
публикует `SessionReminderDueIntegrationEvent` для занятий в окне `[+23 ч, +24 ч]` —
напоминание «завтра». В почте этого достаточно, в мессенджере ждут второе — «через час»,
со ссылкой на онлайн-встречу. В почту такое слать нельзя (спам), в Telegram и приложение — да.

## Что сделать

**Scheduling**
- [ ] `SessionReminderDueIntegrationEvent` → поле `Horizon` (`DayBefore` | `HourBefore`),
      аддитивно, дефолт `DayBefore` для существующих подписчиков. В событие добавить
      `MeetingUrl?` — для кнопки «Войти» (решение зонтика № 9: одна кнопка; для часового
      напоминания это ссылка встречи, если есть, иначе карточка занятия).
- [ ] Job идёт раз в час — для окна «за час» этого мало (разброс от 0 до 60 минут).
      Перевести на `*/10 * * * *` с окнами `[+50, +60 мин]` и `[+23 ч, +24 ч]`, оба
      с защитой от повторной публикации. Сейчас дедупликации нет — она держится на том, что
      часовые окна `[+23 ч, +24 ч]` не пересекаются; при 10-минутном шаге нужны штампы
      `Session.DayReminderSentAtUtc` / `HourReminderSentAtUtc` (миграция), а выборка —
      «в окне и штамп пуст».
- [ ] Не слать часовое напоминание, если занятие отменено/перенесено между суточным и
      часовым (проверка статуса в момент публикации — уже есть для суточного, убедиться).

**Notifications**
- [ ] Новый тип `NotificationTypes.SessionStartingSoon` + шаблон: «Занятие через час» /
      «{{group}} в {{start}}. {{meetingHint}}» / `LinkTemplate` = `MeetingUrl` или карточка.
      Без e-mail-тела — письмо по этому типу невозможно физически, не только по дефолту.
- [ ] `NotificationDefaults`: `InApp` on, `Telegram` on, `Email` — нет тела.
- [ ] `SessionReminderDueIntegrationEventHandler`: ветвление по `Horizon`.
- [ ] Настройки подписок: тип виден в таблице как «Занятие через час» — можно выключить.

**Документация**
- [ ] `docs/02 Модули/Scheduling.md` (job, событие), `docs/02 Модули/Notifications.md`
      (каталог), `.agents/rules/modules/scheduling.md`, `.agents/rules/jobs.md` — если там
      перечислены расписания джобов.

- `Notifications.Tests`: тип в каталоге, без e-mail; дефолты.
