## Ловушки именования

### Group ≠ StudyGroup

`Identity.Group` уже существует в коде — это группа пользователей для назначения ролей
(`GroupRole`, `UserGroup`). Учебная группа — **`StudyGroup`** в модуле [[StudyGroups]].

| | `Identity.Group` | `StudyGroups.StudyGroup` |
|---|---|---|
| Смысл | Массовое назначение прав | Учебный коллектив |
| В UI (ru) | «Группы доступа» | «Группы» |
| Ресурс прав | `Permissions.Groups.*` | `Permissions.StudyGroups.*` |
| Маршрут API | `/api/v1/groups` | `/api/v1/study-groups` |

Подробно: [[ADR-005 Именование Group и StudyGroup]].

### Lesson ≠ Session

`Lesson` — строка в программе курса, существует вне времени.
`Session` — конкретное занятие 12 марта в 18:00 у группы EN-A1-03.

Одна `Lesson` порождает много `Session` (по одному на каждую группу, проходящую курс).
`Session.LessonId` **опционален** — можно провести занятие вне программы (консультация,
отработка). Подробно: [[ADR-006 Урок программы и занятие расписания]].

### Invoice — их два

| | `Billing.Invoice` | `Payments.StudentInvoice` |
|---|---|---|
| Кто платит | Школа → Edvantix | Ученик → школе |
| Кому видно | SuperAdmin + админ школы | Менеджеры школы, ученик, представитель |
| Модуль | [[Billing]] | [[Payments]] |

## Статусы

**`Student.Status`** — `Lead` (заявка) → `Active` → `Paused` → `Archived`

**`StudyGroup.Status`** — `Forming` (набор) → `Active` → `Finished` / `Cancelled`

**`Session.Status`** — `Planned` → `Held` / `Cancelled` / `Rescheduled`

**`Attendance.Status`** — `Present` · `Absent` · `Late` · `Excused`

**`StudentInvoice.Status`** — `Draft` → `Issued` → `PartiallyPaid` → `Paid` / `Cancelled`;
`Overdue` — вычисляемое состояние (`Issued` + `DueDate` в прошлом), не хранится в БД
