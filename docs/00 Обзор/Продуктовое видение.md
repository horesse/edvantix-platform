# Продуктовое видение

← [[Edvantix]]

## Проблема

Онлайн-школы (языковые, IT, музыкальные, репетиторские центры) ведут учёт в связке
«Google Sheets + мессенджер + банковская выписка». Разваливается на: кто в какой группе,
какое занятие когда, кто оплатил, кто пропустил, что проходили в прошлый раз.

## Что делает Edvantix

Единая операционная система школы:

1. **Программа** — курс разложен на разделы и уроки с материалами. Один раз описали —
   переиспользуем для всех групп.
2. **Группы** — набор учеников на курс с преподавателем, вместимостью и сроками.
3. **Расписание** — шаблон повторения → автогенерация занятий → отметка посещаемости.
4. **Оплаты** — тариф → счёт ученику/представителю → менеджер подтверждает поступление.
   Платёжного шлюза нет (см. [[ADR-004 Payments отдельно от Billing]]).
5. **Люди** — ученики, преподаватели, представители, менеджеры с гибкими правами.
6. **Коммуникации** — чат по группам, тикеты поддержки, уведомления.
7. **Прозрачность** — подробный аудит всех действий, вебхуки во внешние системы.

## Бизнес-модель

SaaS: школа регистрируется как тенант, платит по тарифному плану платформы
(модуль [[Billing]]). Внутри школы её собственные деньги — [[Payments]].
Два контура денег принципиально не смешиваются — см. [[ADR-004 Payments отдельно от Billing]].

## Границы MVP

**Входит**

- Курсы → разделы → уроки, материалы уроков (файлы/ссылки)
- Учебные группы, зачисление/отчисление учеников
- Шаблон расписания + автогенерация занятий, перенос и отмена занятия
- Отметка посещаемости преподавателем
- Тарифы, ручное и пакетное выставление счетов, подтверждение оплаты менеджером
- Профили учеников/преподавателей/представителей
- Роли и права, аудит, вебхуки, чат, тикеты, уведомления

**Не входит в MVP (осознанно отложено)**

| Не делаем | Почему |
|---|---|
| Приём платежей онлайн (эквайринг) | Требование сформулировано как «выставление счёта + подтверждение». Шлюз — отдельный проект с юридическими требованиями |
| Оценки, домашние задания с проверкой, тесты | Отдельный крупный домен (LMS-часть). Материалы урока — да, оценивание — нет |
| Видеоконференции внутри платформы | Ссылка на внешний Zoom/Meet в занятии — достаточно |
| Зарплаты преподавателей | Ставка в профиле хранится, расчёт — вручную/выгрузкой |
| Мобильные приложения | Веб-дашборд адаптивный |
| Публичный каталог курсов и самозапись | Заявки заводит менеджер |

## Критерии успеха MVP

- Школа на 200 учеников / 15 преподавателей / 30 групп ведёт месяц работы полностью в системе
- Расписание на месяц генерируется из шаблонов без ручного создания занятий
- Задолженности видны без сведения таблиц вручную
- Любое изменение ученика/оплаты/занятия восстановимо из [[Auditing]]
