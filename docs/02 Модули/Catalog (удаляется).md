# Catalog (удаляется)

← [[Edvantix]] · [[Карта модулей]] · задачи: [[Задачи · Удаление Catalog]]

> 🔴 Удаляется целиком · порядок `600` освобождается под [[Curriculum]]
> Решение — [[ADR-002 Catalog заменяется на Curriculum]]

## Что это

Демонстрационный модуль стартер-кита: витрина интернет-магазина.

| Сущность | |
|---|---|
| `Brand` | производитель |
| `Category` | иерархическая рубрика (родитель/потомок) |
| `Product` | товар: `Money`, `Stock` |
| `ProductImage` | изображение с порядком сортировки |

Доменные события: `ProductCreated`, `ProductPriceChanged`, `ProductStockAdjusted`.
Политика доступа к файлам: `ProductFileAccessPolicy`.

Полный набор срезов: CRUD, поиск с пагинацией, мягкое удаление с корзиной и
восстановлением, загрузка изображений с перестановкой, изменение цены, корректировка
остатков.

## Почему заменяется, а не переименовывается

| `Product` | Курс |
|---|---|
| `Price`, `Money` | цена не свойство курса: один курс продаётся помесячно, за пакет и индивидуально → `Tariff` в [[Payments]] |
| `Stock` | у курса нет остатка; вместимость — свойство группы |
| `Brand` | не имеет смысла |
| плоская сущность | курс — дерево: разделы → уроки → материалы |
| `ProductImage` | материалы разнородны: файл, видео, ссылка, домашнее задание, с флагом видимости |

Полное обоснование — [[ADR-002 Catalog заменяется на Curriculum]].

## Ценность до удаления

Catalog — эталон конвенций проекта. Паттерны копируются в [[Curriculum]]:

| Из Catalog | Куда |
|---|---|
| `Category` + `GetCategoryTree` | `Subject` — та же иерархия |
| `ProductImage` + `ReorderProductImages` | `LessonMaterial` — сортировка и перестановка |
| Мягкое удаление + `ListTrashed*` + `Restore*` | все сущности Curriculum |
| `ProductFileAccessPolicy` | `LessonMaterialAccessPolicy` |
| Структура срезов, валидаторы, спецификации, маппинги | 1:1 |

> [!tip] Порядок работ
> Сначала [[Curriculum]] работает и покрыт тестами — потом удаление, отдельным PR.
