# ADR-002 Catalog заменяется на Curriculum

← [[Edvantix]]

**Статус:** принято · 2026-08-09

## Контекст

Модуль `Catalog` (порядок 600) — демонстрационная витрина интернет-магазина из
стартер-кита: `Brand`, `Category` (иерархия), `Product` (`Money`, `Stock`), `ProductImage`.
Полный набор срезов CRUD, поиск, мягкое удаление, корзина, загрузка изображений.

Предметная область Edvantix требует учебной программы: курсы, разделы, уроки, материалы.
Поверхностно похоже на каталог товаров.

Варианты:

1. Удалить Catalog, написать `Curriculum` с нуля.
2. Переименовать сущности Catalog в учебные с миграцией.
3. Оставить Catalog как витрину продаваемых пакетов + отдельный `Curriculum`.

## Решение

**Вариант 1: удалить целиком, написать `Curriculum` заново**, заняв освободившийся
порядок `600`.

## Обоснование

Сходство поверхностное, различия структурные:

| Product | Курс |
|---|---|
| `Price`, `Money` — цена свойство товара | цена не свойство курса: один курс продаётся помесячно, за пакет и индивидуально → `Tariff` в [[Payments]] |
| `Stock` — остаток | у курса нет остатка; вместимость — свойство группы |
| `Brand` | не имеет смысла |
| плоская сущность | курс — дерево: разделы → уроки → материалы |
| `ProductImage` — однородные картинки | материалы разных видов: файл, видео, ссылка, домашнее задание, с флагом видимости ученикам |

Переименование протащило бы четыре чужих поля и девять миграций в новый домен.
Через полгода пришлось бы объяснять, почему у урока есть `StockQuantity` и
`BrandId`. Стоимость написания с нуля ниже стоимости этого долга.

Вариант 3 отвергнут: две сущности «курс» (продаваемая и учебная) — источник постоянной
путаницы, а продаваемая единица уже есть — `Tariff`.

## Последствия

**Положительные**

- Домен чистый, поля осмысленные
- Освобождается порядок 600
- Уходят демо-данные товаров

**Отрицательные / принимаемые**

- Пишем ~25 срезов вместо переименования
- Теряем эталонный пример конвенций → **смягчение:** паттерны копируются
  до удаления (иерархия `Category`, сортировка `ProductImage`, корзина,
  `ProductFileAccessPolicy`)

**Порядок работ**

Catalog удаляется **после** того, как [[Curriculum]] написан и проходит тесты, —
отдельным PR. Держать как справочник до этого момента.
