# Dashboard (школа)

← [[Edvantix]] · [[Карта экранов]] · задачи: [[Бэклог]]

`clients/dashboard` · порт **5174** · рабочее место школы. Здесь работают все роли, кроме
`SuperAdmin`: администратор школы, менеджеры, преподаватели, ученики, представители.

Основной объём фронтенд-работы — здесь.

## Стек

React 19 · Vite 7 · TypeScript · TanStack Query v5 · React Router 7 · Radix + Tailwind v4
(shadcn-style) · SignalR + SSE · Playwright (route-mocked).

Конфигурация — рантайм-`/config.json`, **не** `VITE_*`.
API-клиент — рукописный `apiFetch` (`src/lib/api-client.ts`), кодогенерации нет.

Правила — `.agents/rules/frontend/shared.md` и `.agents/rules/frontend/dashboard.md`.

> [!danger] Правило 9 из `AGENTS.md`
> Данные для конкретного вызова передавать через `mutate(arg)`, **никогда** через
> состояние, которое замыкают колбэки мутации — гонка на момент выполнения.
> Самая частая ошибка в этом коде.

## Роли и стартовые страницы

Разводить приложения не нужно — разные стартовые маршруты и навигация по правам.

| Роль | Стартовая страница | Особенность |
|---|---|---|
| Manager | сводка школы | занятия сегодня, новые заявки, просроченные счета |
| Teacher | своё расписание | быстрая отметка посещаемости с карточки занятия |
| Student | своё расписание | материалы, свои счета |
| Guardian | подопечные | переключатель ученика, если их несколько |

Полный перечень экранов — [[Карта экранов]], работы — [[Бэклог]].

## Навигация

`src/components/layout/nav-data.ts` — секции с полями `perm` / `anyPerm`. Пункт скрывается,
когда прав нет, чтобы пользователь не упирался в 403.

> [!important] Право в `nav-data.ts` зеркалит право эндпоинта
> Гейт пункта меню = право основного списочного эндпоинта страницы. Меняется на сервере —
> меняется здесь. Та же конвенция, что в `lib/trash-permissions.ts`.

Предлагаемая структура меню:

```
Обзор
Расписание
Группы
Ученики
Преподаватели
Программа
  ├─ Курсы
  └─ Направления
Оплаты
  ├─ Счета
  ├─ Тарифы
  └─ Должники
Чат
Обращения
Файлы
Администрирование
  ├─ Пользователи
  ├─ Роли
  ├─ Группы доступа
  ├─ Аудит
  ├─ Сессии
  └─ Корзина
Подписка
Школа
  ├─ Настройки школы   (Permissions.SchoolSettings.Manage)
  ├─ Аудитории         (Permissions.Scheduling.Rooms.View)
  └─ Нерабочие дни     (Permissions.Scheduling.ScheduleTemplates.View)
Настройки   (личные: профиль, безопасность, оформление, уведомления, API-ключи)
```

> [!note] Раздел «Школа» — тенант-скоуп, отдельно от личных «Настроек»
> Настройки школы (часовой пояс, валюта, нумерация счетов) плюс справочники
> аудиторий и нерабочих дней вынесены в самостоятельный раздел `/school/*`.
> Старые пути `/settings/{school,rooms,non-working-days}` оставлены редиректами.

## API-модули

`src/api/` — по модулю на предметную область: `audits.ts`, `billing.ts`, `chat.ts`,
`files.ts`, `health.ts`, `identity.ts`, `notifications.ts`, `permissions-catalog.ts`,
`sessions.ts`, `tickets.ts` (плюс `catalog.ts`, который уходит).

Каждый — тонкая обёртка над `apiFetch` с типами DTO и ключами запросов TanStack Query.
Кодогенерации нет: типы пишутся руками по контрактам модуля.

> [!note] `permissions-catalog.ts` — каталог прав из [[Identity]]
> К удаляемому модулю Catalog отношения не имеет. Слепой поиск по строке `catalog`
> зацепит и его.

## Реальное время

SignalR — чат и обновления расписания. SSE — лента уведомлений.
При переносе занятия открытый у преподавателя календарь обновляется без перезагрузки.

## Тесты

Playwright с моками маршрутов (`clients/dashboard/tests/`). Обязательное покрытие —
всё, что двигает деньги или расписание: отметка посещаемости, выставление счёта,
подтверждение оплаты, зачисление в группу.
