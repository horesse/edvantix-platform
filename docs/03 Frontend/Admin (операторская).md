# Admin (операторская)

← [[Edvantix]] · [[Карта экранов]] · задачи: [[Бэклог]]

`clients/admin` · порт **5173** · приложение оператора платформы (`SuperAdmin`).
Здесь управляют школами-тенантами, планами и подписками — **не** учебным процессом.

## Отличие от dashboard

| | admin | dashboard |
|---|---|---|
| Кто | оператор Edvantix | сотрудники и клиенты школы |
| Область | все тенанты | один тенант |
| Формы | react-hook-form + zod | без zod |
| Изменений по Edvantix | минимум | основной объём |

## Что есть

| Раздел | Файлы | Судьба |
|---|---|---|
| Тенанты | `pages/tenants/list, create, detail` | 🔧 терминология: «Школы» |
| Пользователи | `pages/users/*` | ✅ |
| Роли | `pages/roles/*` | ✅ |
| Биллинг платформы | `pages/billing/plans-list, invoices-list, invoice-detail` | ✅ |
| Аудит | `pages/audits/*` | ✅ кросс-тенантный |
| Вебхуки | `pages/webhooks/*` | 🔧 пополнить каталог событий |
| Имперсонация | `pages/impersonation/list` | ✅ |
| Уведомления | `pages/notifications/inbox` | ✅ |
| Здоровье | `pages/health/page` | ✅ |
| Настройки | `pages/settings/*` | ✅ |
| Дашборд | `pages/dashboard.tsx` | 🔧 показатели платформы |

Работы по приложению — [[Бэклог]].

## Чего здесь быть не должно

Ученики, группы, расписание, счета учеников. Это данные школы, оператор их не ведёт.
Посмотреть при разборе обращения — через **имперсонацию** в dashboard, с записью
в [[Auditing]].

> [!warning] Соблазн «оператор сделает быстрее»
> Возникнет желание добавить в admin экран «все ученики всех школ» для поддержки.
> Это ломает изоляцию ([[Мультитенантность]]) и создаёт кросс-тенантную утечку.
> Правильный путь — имперсонация: журналируется, ограничена правами, отзываема.
